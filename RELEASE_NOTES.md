# Track Defaults v1.0.0

Choose default audio and subtitle tracks for individual videos or batches on Windows.

- Inspect embedded tracks and their languages.
- Choose defaults individually or apply language choices across a batch.
- Review missing or ambiguous matches manually.
- Save new copies without changing originals or re-encoding audio/video.
- Supports MKV, MP4, M4V, and MOV.

Download **Track Defaults-Windows-x64.zip**, extract it, and open **Track Defaults.exe**. Python and video tools are included; no installer is required.

Requires 64-bit Windows 10/11. This build is unsigned. Player language preferences can override file defaults.

Copies go into a **Track Defaults** subfolder beside the first video added, unless you change **Save copies to**.
